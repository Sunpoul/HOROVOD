# Шаблоны

Готовые проекты, которые видят все пользователи: ряд «Шаблоны» на главной. Нажатие на карточку создаёт копию в проектах человека, сам шаблон не меняется.

## Как добавить шаблон

1. Откройте редактор в режиме автора: добавьте к адресу `?author=1` (например, `https://horovod.su/app.html?author=1`) или в Mini App семь раз подряд нажмите на строку «HRVD · Beta …» в меню профиля.
2. Соберите проект, вернитесь на главную, у карточки проекта нажмите «⋯» → «Сохранить как шаблон». Впишите название и короткое описание.
3. Файл `template-….json` положите в эту папку (можно переименовать, порядок на главной — по имени файла: `01-афиша.json`, `02-релиз.json`).
4. Выполните `python3 build.py`: он обновит `templates/index.json` (список для главной).
5. Закоммитьте папку и сделайте `git push origin main`. Через минуту шаблон появится у всех.

Чтобы убрать шаблон, удалите его файл и снова выполните `python3 build.py`.

Лёгкие шаблоны открываются быстрее: лучше из текста, фигур, стикеров и небольших картинок. Видео и музыка в шаблоне увеличивают файл. Шрифты из каталога приложения (в том числе Tsarevich Neo, Puff, Pressure, Modular Wide) уже встроены и в файл не попадают.
