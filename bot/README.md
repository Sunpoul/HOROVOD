## Вариант 1: без сервера (только BotFather)

Подходит, если достаточно экрана перед запуском: Telegram показывает картинку, описание и свою кнопку **START**, а Mini App открывается кнопкой меню рядом с полем ввода.

1. `/mybots` → ваш бот → **Edit Bot** → **Edit Description**: вставьте описание из таблицы.
2. **Edit Bot** → **Edit About**: вставьте строку «О боте».
3. **Edit Bot** → **Edit Description Picture**: отправьте `description-640x360.png`.
4. **Edit Bot** → **Edit Botpic**: отправьте `avatar-640.png`.
5. **Bot Settings** → **Menu Button** → **Configure menu button**: адрес `https://horovod.su/`, название `HOROVOD`.

Сообщения с кнопкой «Начать» после нажатия START в этом варианте не будет: боту нечем отвечать, пока он не запущен.

## Вариант 2 (основной): Telegram Serverless — бот работает всегда, без своего сервера

Код бота лежит в папке [`tgcloud/`](../tgcloud) и работает на инфраструктуре Telegram ([документация](https://core.telegram.org/bots/serverless)). На любое личное сообщение (`/start`, `/help`, любой текст) бот присылает приветственный пост с кнопкой «Начать». Группы игнорирует.

| Файл | Что внутри |
|---|---|
| `tgcloud/handlers/message.js` | Обработчик входящих сообщений |
| `tgcloud/lib/texts.js` | Все тексты, адрес Mini App, ссылка на картинку, `SETUP_VERSION` |
| `tgcloud/lib/welcome.js` | Приветственный пост и применение настроек бота |
| `tgcloud/lib/store.js`, `tgcloud/schema.js` | Таблица `settings` (ключ — значение) во встроенной базе |
| `tgcloud.jsonc` | Конфиг проекта Serverless |

Как запустить (один раз, из корня репозитория, нужен Node):

1. В @BotFather: `/mybots` → `@gethorovod_bot` → включите **Serverless**.
2. `npx tgcloud login` — привязать бота. Токен CLI сохраняется в `.tgcloud/` (папка в `.gitignore`, в репозиторий не попадает).
3. `npx tgcloud migrate` — создать таблицу `settings`.
4. `npx tgcloud push` — загрузить код.
5. Напишите боту `/start`. Первое сообщение после деплоя само применит команды, описание, строку «О боте» и кнопку меню; картинку над описанием и аватар по-прежнему ставят в BotFather (вариант 1, шаги 3–4).

Как это устроено:

- **Картинка приветствия.** В Serverless нет файловой системы, поэтому Telegram скачивает `welcome-1280x720.png` по ссылке `https://horovod.su/brand/telegram/…` (её раздаёт GitHub Pages). После первой отправки бот сохраняет `file_id` и дальше шлёт его. Если картинка недоступна (например, домен ещё не подключён), бот отправит тот же текст с кнопкой без картинки.
- **Поменять тексты.** Правьте `tgcloud/lib/texts.js`, увеличьте `SETUP_VERSION` и сделайте `npx tgcloud push`. Следующее сообщение боту применит новые описание и команды и заново загрузит картинку.
- **Проверить без деплоя:** `npx tgcloud run handlers/message '{ chat: { id: <ваш chat id>, type: "private" }, text: "/start" }'`.
- Логика проверена на подставном SDK (приветствие, кэш картинки, запасной вариант без картинки, игнор групп). С настоящим Serverless её нужно один раз прогнать самому: сервис новый (CLI 0.2), формат `tgcloud.jsonc` может потребовать полей, которых нет в документации. Если `push` ругается на конфиг — выполните `npx tgcloud init`, оставив файлы из `tgcloud/` как есть.

## Вариант 3: локальный скрипт (для отладки)

Скрипт `horovod-bot.mjs` без зависимостей (нужен Node 18 или новее). Он отвечает на любое личное сообщение приветственным постом с кнопкой «Начать». При запуске он сам задаёт команды, описание, строку «О боте» и кнопку меню (картинку над описанием и аватар придётся поставить в BotFather, как в варианте 1).

```bash
BOT_TOKEN=<токен из @BotFather> node bot/horovod-bot.mjs
```

- Токен вводите только в своём терминале и никому не отправляйте. Скрипт берёт его из переменной окружения, не сохраняет и не печатает.
- Бот работает, пока запущен скрипт. Чтобы он отвечал всегда, запустите его на сервере или на компьютере, который не выключается (например, через `pm2` или `launchd`).
- Если адрес Mini App изменится, задайте `APP_URL=https://...` при запуске.
- Скрипт проверен на подставном API Telegram: на `/start` уходит картинка с подписью и кнопкой, повторные ответы используют уже загруженный файл, групповые чаты игнорируются. С настоящим Telegram и вашим токеном его нужно один раз запустить самому.
